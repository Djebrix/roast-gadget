A single original line roasting a gadget used every day: the robot vacuum that mapped the whole flat in one afternoon, then spent every morning since eating the same charging cable. See the competition at https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610.

## Run

```sh
python3 main.py
```

This writes the one-liner to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
